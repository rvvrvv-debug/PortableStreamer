================================================================
  GstScheduler — Playout Server v2.02
  Плановый стример для трансляций на CDN
================================================================

ЧТО ЭТО

Программа в назначенное время автоматически запускает трансляцию:

    заставка (картинка) -> основной видеоролик -> финальная заставка

и отправляет её на CDN (YouTube, Twitch, CDNvideo или любой RTMP-сервер).

Поставили время, нажали ПУСК — можно заниматься другими делами.
Эфир начнётся сам, даже если окно свёрнуто.


ТРЕБОВАНИЯ

  • Windows 10 или Windows 11 (64-бит)
  • Свободные порты 1935 и 8554
  • Разрешение в антивирусе/брандмауэре для PortableStreamer.exe,
    mediamtx.exe и gst-launch-1.0.exe
  • Видеокарта не обязательна: без неё программа переключится на CPU


ЗАПУСК

  1. Распакуйте папку целиком (не запускайте из архива).
  2. Запустите PortableStreamer.exe.
  3. Заполните параметры кодирования, источники, адрес CDN.
  4. Укажите время старта и нажмите ПУСК.

В папке лежат ДВА исполняемых файла:

      PortableStreamer.exe     — трансляция по RTMP (обычный режим)
      PortableStreamerSRT.exe  — та же программа, но отдаёт поток по SRT

Запускать можно только один из них одновременно: второй покажет
предупреждение и закроется.

SRT-ВЕРСИЯ

  Поля адреса в ней означают:

      «SRT адрес» — srt://хост:порт приёмника
                    например: srt://192.168.1.50:9000
      «Stream ID» — нужен не всем приёмникам; если не требуется,
                    оставьте поле пустым

  Остальное — кодирование, заставки, тестовый цикл, логи — работает
  так же, как в обычной версии.

  Примечание: SRT-версия слушает UDP-порт 8890 на всех интерфейсах
  (так требует реализация SRT в MediaMTX). Windows может один раз
  спросить разрешение для брандмауэра — разрешите для частных сетей.

Программа портативная: установка не требуется, настройки хранятся
в файле GstScheduler.cfg рядом с программой.

Одновременно может работать только ОДИН экземпляр программы:
второй запуск покажет предупреждение и закроется сам.
Так сделано специально — два экземпляра конфликтуют за порты 1935 и 8554.

При старте программа закрывает процессы, оставшиеся от прошлого запуска
(MediaMTX, GStreamer). Это нужно, если предыдущая копия была закрыта
аварийно: иначе они держат порты и мешают удалить папку.

БРАНДМАУЭР

  Внутренние порты (1935, 8554, 8890) программа открывает ТОЛЬКО на этом
  компьютере — на адресе 127.0.0.1. Поэтому Windows Firewall не должен
  спрашивать разрешения при каждом запуске.

  Если запрос всё же появился — он относится к первому запуску нового exe:
  разрешите доступ для «частных сетей». Исходящее соединение с CDN
  в разрешениях не нуждается.


КАКИЕ ФАЙЛЫ ПОДДЕРЖИВАЮТСЯ

  • Контейнеры: MP4, MOV, M4V
  • Видео: H.264
  • Звук: AAC, MP3, PCM (приводится автоматически)

  НЕ поддерживаются: MKV, AVI, WMV, а также видео H.265/HEVC,
  VP9, AV1 и файлы с несколькими звуковыми дорожками.

  Если нужен другой формат — пересохраните файл в MP4 (H.264 + AAC)
  в любом видеоредакторе (DaVinci Resolve, HandBrake, ffmpeg).

  Файл без звуковой дорожки поддерживается: вместо звука
  добавляется тишина, синхронизация не нарушается.


ТЕСТОВЫЙ ЦИКЛ (второй режим)

  Сверху, в блоке «Настройки трансляции», поле «Режим»:

      Эфир по расписанию — обычный режим (заставка → файл → финал)
      Тестовый цикл     — непрерывный тестовый поток

  В тестовом цикле:

  • «Длительность» — сколько минут держать поток (0 = до остановки).
  • «Источник» — что гонять по кругу:
        Цикл: файл Main Video        — повтор выбранного видеофайла
        Цикл: картинка + тон 1 кГц   — одна картинка и ровный тон
        Цикл: картинка + MP3         — картинка и выбранный звуковой файл
        Цикл: тестовая таблица       — таблица SMPTE + щелчки раз в секунду

    Для варианта «картинка + MP3» сразу откроется выбор звукового файла
    (mp3, m4a, aac, wav). Файл запоминается в профиле. Звук повторяется
    вместе с картинкой и обрезается точно по её длине — рассинхрона нет.
  • «Часы на экране» — показывает текущее время в правом верхнем углу.
    Удобно для замера задержки: сравните часы на картинке с часами
    на столе.

  В тестовом цикле заставки НЕ используются: поток идёт от начала
  до конца без intro и outro. Поля Intro/Outro в этом режиме неактивны.
  Поток стартует сразу после нажатия «ЗАПУСТИТЬ ТЕСТ» и останавливается
  сам по истечении указанного времени.


НАСТРОЙКА CDN

  Поле «RTMP URL» — адрес сервера, например:
      rtmp://a.r.cdnvideo.net/livemaster/

  Поле «Stream Key» — ключ потока из личного кабинета провайдера.

  Если оба поля пустые — эфир пойдёт только локально (в MediaMTX),
  зрители на CDN его не увидят. Программа предупредит об этом.

  Состояние отправки видно в плашке «CDN» под окном превью:
      подключение...   — связывается с провайдером
      публикация идёт  — поток принят
      ОТКАЗ 403 / 401  — провайдер не пустил поток (проверьте ключ)
      остановлен      — эфир завершён


ЗАСТАВКИ И ДЛИТЕЛЬНОСТЬ

  • Intro: минимум 40 секунд, по умолчанию 60.
    Это время нужно CDN, чтобы поднять поток и стабилизировать раздачу.
  • Outro: 60 секунд.
  • Можно использовать свою картинку (JPG/PNG) или встроенную.


ЛОГИ

  Папка: %TEMP%\GstScheduler\prep\
  (например, C:\Users\Имя\AppData\Local\Temp\GstScheduler\prep\)

  Чтобы не искать её вручную, в программе есть кнопка
  «Открыть логи» (внизу слева). Рядом показан точный путь.

  stream_log_<ID>.txt    — что играло и с какими параметрами
  mediamtx_log_<ID>.txt  — работа медиасервера и связь с CDN
  preview_log_<ID>.txt   — работа превью

  У SRT-версии к имени добавляется «srt»:
      stream_log_srt_<ID>.txt

  Логи ведутся с историей: каждый прогон сохраняется отдельным файлом,
  хранятся последние 20. Ключ потока в логах маскируется (заменяется на ***).

  Идентификатор компьютера (8 символов) стоит в имени КАЖДОГО файла —
  и активного, и архивного:

      stream_log_3F7A21C4.txt                       — текущий прогон
      stream_log_3F7A21C4_2026-11-05_18-33-05.txt   — архив

  Поэтому логи с разных машин можно складывать в одну папку — ничего
  не перезапишется. Идентификатор хранится в файле machine.id рядом
  с программой.

  При обращении за помощью прикладывайте папку prep целиком.


ОГРАНИЧЕНИЯ

  • Одновременно может работать только один экземпляр программы.
  • Порты 1935 и 8554 должны быть свободны.
  • Формат файлов — только MP4/MOV/M4V.
  • CDN может задерживать старт раздачи на 20–40 секунд;
    именно для этого нужна заставка.
